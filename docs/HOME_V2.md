## 디자인과 현재 API의 차이

- **사용자가 확인한 미납**: 기존 명세의 `UNPAID`는 ‘기한 경과·정기 금액 미충족’이다. 새 디자인은 사용자 확인이 있어야 빨간 ‘미납’이다. 현재 응답만으로 둘을 구분할 수 없어, 기록 없는 기한 경과는 **납부 미기록**으로 표시한다. 빨간 미납 컴포넌트는 준비했지만, 사용자 확인을 저장·조회할 API가 추가되어야 운영 화면에서 연결할 수 있다. 임의의 API 필드는 추가하지 않았다.
- **버틸 수 있는 폭**: 금리·소득·선택 지출의 ‘기본 상환/추가 상환 유지 변화 폭’은 현 명세에 없다. `rate_thresholds`는 절대 금리 임계값이므로 변화 폭으로 바꿔 표시하지 않았다.
- **론런 시작 전/후 원금 색상 분리**: 현재 대시보드에는 시작 전 상환 비율이 없다. 전체 상환 비율은 응답으로 표시하며, 진한 구간을 임의로 생성하지 않는다.
- Figma 예시 금액·위험도와 실제 Mock 응답의 수치는 다를 수 있다. 디자인을 맞추기 위해 화면에 금액을 고정하지 않았다.
