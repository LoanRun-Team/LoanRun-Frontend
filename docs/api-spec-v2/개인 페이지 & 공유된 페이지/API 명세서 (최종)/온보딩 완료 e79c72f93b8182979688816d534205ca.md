**기능:** 온보딩 완료

**HTTP method:** `POST`

**API Endpoint:** `/api/onboarding/complete/`

**인증:** 필수 (Authorization: Bearer {access_token})

## Request

요청 파라미터 및 Body 없음.

**요청 예시**

```jsx
POST /api/onboarding/complete/
Authorization: Bearer <access_token>
```

Body 없음.

## Response

### 성공 200

```json
{
  "success": true,
  "code": "ONBOARDING_COMPLETE_SUCCESS",
  "message": "온보딩을 완료했습니다.",
  "data": {
    "completed": true,
    "dashboard_ready": true
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| `completed` | boolean | completed 값(공통 규약) |
| `dashboard_ready` | boolean | dashboard ready 값(공통 규약) |

### 실패 응답

**실패 400 · ONBOARDING_INCOMPLETE**

```json
{
  "success": false,
  "code": "ONBOARDING_INCOMPLETE",
  "message": "필수 온보딩 정보가 누락되었습니다.",
  "errors": {
    "missing_steps": [
      "REPAYMENT_GOAL"
    ]
  }
}
```

**실패 401 · AUTH_REQUIRED**

```json
{
  "success": false,
  "code": "AUTH_REQUIRED",
  "message": "로그인이 필요합니다.",
  "errors": {}
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `ONBOARDING_INCOMPLETE` | 필수 온보딩 정보가 누락되었습니다. |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- 활성 대출 1개 이상, 재정 프로필(소득 유형별 필수값, 고정/변동 필수 지출), 활성 대출별 목표 완납일/성향 또는 기본 만기 계획 확인 후 완료. 반복 호출 동일; 개인 대출 연동은 완료 조건 아님.

**화면/기능 연결:** A 등록 완료; 각 단계 저장 API 재사용.

- 지원 4종 대출, 실제 약정의 중도상환 정책 및 필요한 만기일시 적립 계획 검증 후 완료. 기본 재정정보 및 목표는 기존 API 재사용.
