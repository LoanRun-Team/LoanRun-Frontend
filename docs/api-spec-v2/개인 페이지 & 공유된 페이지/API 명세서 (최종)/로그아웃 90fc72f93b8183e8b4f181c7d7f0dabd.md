# 로그아웃

API Endpoint: /api/auth/logout/
FE 연동: No
HTTP method: POST
Status: BE 구현전
Test: No
model: users
메모: G1-e 로그아웃; 갱신 토큰 무효화.
순서: 4

**기능:** 로그아웃

**HTTP method:** `POST`

**API Endpoint:** `/api/auth/logout/`

**인증:** 필수 (Authorization: Bearer {access_token})

## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| refresh_token | string | 필수 | 현재 갱신 토큰 |

**요청 예시**

```jsx
POST /api/auth/logout/
Authorization: Bearer <access_token>
Content-Type: application/json
```

```json
{
  "refresh_token": "sample.refresh.token"
}
```

## Response

### 성공 200

```json
{
  "success": true,
  "code": "LOGOUT_SUCCESS",
  "message": "로그아웃했습니다.",
  "data": {
    "logged_out": true
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| logged_out | boolean | — |

### 실패 응답

**실패 400 · INVALID_REFRESH_TOKEN**

```json
{
  "success": false,
  "code": "INVALID_REFRESH_TOKEN",
  "message": "갱신 토큰을 확인해 주세요.",
  "errors": {}
}
```

**실패 401 · AUTH_REQUIRED**

```json
{
  "success": false,
  "code": "AUTH_REQUIRED",
  "message": "로그인이 필요합니다.",
  "errors": {}
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `INVALID_REFRESH_TOKEN` | 갱신 토큰을 확인해 주세요. |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- 갱신 토큰 서버 무효화. 클라이언트 로컬 토큰 삭제. 이미 무효화된 토큰 재요청도 성공 처리 가능. 세션 폐기 여부를 인증 시 검증하여 기존 액세스 토큰도 즉시 거부. 탈퇴 계정은 즉시 접근 차단.
