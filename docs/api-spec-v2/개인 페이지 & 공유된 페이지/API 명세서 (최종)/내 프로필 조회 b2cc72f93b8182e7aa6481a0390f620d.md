**기능:** 내 프로필 조회

**HTTP method:** `GET`

**API Endpoint:** `/api/users/me/`

**인증:** 필수 (Authorization: Bearer {access_token})

## Request

요청 파라미터 및 Body 없음.

**요청 예시**

```jsx
GET /api/users/me/
Authorization: Bearer <access_token>
```

Body 없음.

## Response

### 성공 200

```json
{
  "success": true,
  "code": "USER_DETAIL_SUCCESS",
  "message": "프로필을 조회했습니다.",
  "data": {
    "user_id": 1,
    "email": "demo@example.com",
    "name": "민준",
    "occupation": "직장인",
    "income_type": "REGULAR",
    "onboarding_completed": true,
    "plan_type": "PRO"
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| user_id | integer | 사용자 식별자 |
| email | string | — |
| name | string | — |
| occupation | string | — |
| income_type | string | — |
| onboarding_completed | boolean | — |
| plan_type | string | FREE 또는 PRO |

### 실패 응답

**실패 401 · AUTH_REQUIRED**

```json
{
  "success": false,
  "code": "AUTH_REQUIRED",
  "message": "로그인이 필요합니다.",
  "errors": {}
}
```

**실패 404 · USER_NOT_FOUND**

```json
{
  "success": false,
  "code": "USER_NOT_FOUND",
  "message": "사용자를 찾을 수 없습니다.",
  "errors": {}
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |
| 404 | `USER_NOT_FOUND` | 사용자를 찾을 수 없습니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

- 인증 사용자 기준. profile의 income_type과 동일 값을 반환.
