**기능:** 요금제 정보 조회

**HTTP method:** `GET`

**인증:** 필수 (Authorization: Bearer {access_token})

## Request

요청 파라미터 및 Body 없음.

**요청 예시**

```jsx
GET /api/settings/subscription/
Authorization: Bearer <access_token>
```

Body 없음.

## Response

### 성공 200

```json
{
  "success": true,
  "code": "SUBSCRIPTION_DETAIL_SUCCESS",
  "message": "요금제 정보 정보를 조회했습니다.",
  "data": {
    "plan_type": "PRO",
    "pro_features": [
      "RISK_ANALYSIS",
      "AI_REPORT",
      "OVERALL_STRATEGY_PLAN"
    ],
    "billing_enabled": false,
    "free_features": [
      "LOANS",
      "INDIVIDUAL_PLANS",
      "BUDGETS",
      "PAYMENTS",
      "DASHBOARD"
    ]
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| `plan_type` | string | FREE 또는 PRO |
| `pro_features` | array<string> | pro features 값(공통 규약) |
| `billing_enabled` | boolean | billing enabled 값(공통 규약) |
| `free_features` | array | 무료 제공 기능 목록 |

### 실패 응답

**실패 401 · AUTH_REQUIRED**

```json
{
  "success": false,
  "code": "AUTH_REQUIRED",
  "message": "로그인이 필요합니다.",
  "errors": {}
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- 가입 FREE, 시연 PRO seed, 결제/전환 API 없음. PRO는 위험 분석, 상환 리포트 전체, 그 안에서 반영된 다중 전체 계획만. 예산/지출·개별 계획·기록 무료. 해지 시 기존 대출별 금액/기록 유지, 전체 계획/우선순위/리포트/위험 접근만 차단.

**화면/기능 연결:** G1-c FREE/PRO 서버 권한; 결제 제외, 시연 PRO seed.
