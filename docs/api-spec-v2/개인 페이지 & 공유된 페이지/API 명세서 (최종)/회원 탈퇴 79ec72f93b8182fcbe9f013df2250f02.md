# 회원 탈퇴

API Endpoint: /api/users/me/
FE 연동: No
HTTP method: DELETE
Status: BE 구현전
Test: No
model: users
메모: G1-e 탈퇴; 본인 데이터 및 토큰 삭제.
순서: 7

**기능:** 회원 탈퇴

**HTTP method:** `DELETE`

**API Endpoint:** `/api/users/me/`

**인증:** 필수 (Authorization: Bearer {access_token})

## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| confirm | boolean | 필수 | true일 때만 탈퇴 진행 |

**요청 예시**

```jsx
DELETE /api/users/me/
Authorization: Bearer <access_token>
Content-Type: application/json
```

```json
{
  "confirm": true
}
```

## Response

### 성공 200

```json
{
  "success": true,
  "code": "USER_DELETE_SUCCESS",
  "message": "회원 탈퇴를 완료했습니다.",
  "data": {
    "deleted": true
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| `deleted` | boolean | deleted 값(공통 규약) |

### 실패 응답

**실패 400 · CONFIRMATION_REQUIRED**

```json
{
  "success": false,
  "code": "CONFIRMATION_REQUIRED",
  "message": "회원 탈퇴를 확인해 주세요.",
  "errors": {
    "confirm": [
      "true로 설정해야 합니다."
    ]
  }
}
```

**실패 401 · AUTH_REQUIRED**

```json
{
  "success": false,
  "code": "AUTH_REQUIRED",
  "message": "로그인이 필요합니다.",
  "errors": {}
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `CONFIRMATION_REQUIRED` | 회원 탈퇴를 확인해 주세요. |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- FE 확인 모달 후 본인 계정과 대출·납부·계획·재정·리포트·설정·토큰을 트랜잭션으로 삭제하고 접근 차단한다. 다른 사용자 데이터에는 영향 없음. 개인정보 포함 원문 로그 저장 금지.
- income entries, 전체 전략 계획/버전, 비교 및 리포트 작업도 파기 범위.
- 회원 탈퇴는 대출 soft delete와 달리 계정 및 개인정보·기록 삭제. 토큰 폐기. 보존 대상 법정 데이터가 없는 MVP 기준.**화면/기능 연결:** G1-e 탈퇴; 본인 데이터 및 토큰 삭제.
