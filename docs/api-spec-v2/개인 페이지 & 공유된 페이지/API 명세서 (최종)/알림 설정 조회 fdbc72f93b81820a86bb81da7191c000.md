## Response

### 성공 200

```json
{
  "success": true,
  "code": "NOTIFICATION_SETTINGS_SUCCESS",
  "message": "알림 설정 정보를 조회했습니다.",
  "data": {
    "payment_due": true,
    "report_update": true,
    "rate_reset": true,
    "grace_end": true
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| `payment_due` | boolean | payment due 값(공통 규약) |
| `report_update` | boolean | 기준 날짜(YYYY-MM-DD) |
| `rate_reset` | boolean | 금리 재설정일 알림 |
| `grace_end` | boolean | 거치 종료일 알림 |

### 실패 응답

**실패 401 · AUTH_REQUIRED**

```json
{

  "message": "로그인이 필요합니다.",

```
