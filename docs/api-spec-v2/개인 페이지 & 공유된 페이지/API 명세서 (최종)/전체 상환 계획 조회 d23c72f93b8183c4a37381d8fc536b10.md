## 처리 규칙 및 개발 참고

- FREE 403 PRO_REQUIRED. 활성 0~1개 SINGLE_LOAN, 다중 전략 미반영 EMPTY, 적용 후 AVAILABLE. 개별 원금·금액은 유지, 적립/예상 비용 분리, 수기 장기 수정은 MANUAL로 변경.
- 장기 목표(target_payoff_date)와 실제 속도 기준 projected_payoff_date 분리. target_date는 사용자 입력 목표, estimated_payoff_date 호환 키=projected_payoff_date. 계획 미리보기에는 제안 계획 기준 예상일도 별도 표시. 목표일은 계약 만기 이내, 목표일 역산은 공통 엔진 최소 월 추가액. 계산 자체 불가능한 목표는 오류, 재정 여유 초과 장기 목표는 부족액 경고 후 저장 가능. 기본 약정·기록 변경 없음.
- FAST/BALANCED/STABLE=전체 반복 월 배분 가능액의 80/50/0%, HALF_UP 원 단위(5만원 내림 없음), 전체 가계 기준 한 번만 계산; 여러 대출은 지정 배분 합계 검증. 저장 목표액은 변경 전까지 유지. 월 배분만 변경하면 해당 월만 override, 장기 목표/전략 변경 없음. 거치 중 추가 계획 없음, 만기일시 target 및 적립 목표 별도.
- 가계 recurring_cap=max(B,0), B는 이월 전 재정 잔여액. 당월 배분 cap은 이월 포함 및 이미 실제 사용/적립한 자금 고려. 장기 재정 부족 경고만, 전략 실제 적용과 당월 override는 cap 이하. 대출별 금액은 기본 빚 및 적립·수수료를 구분.
- 계획 진행률은 계획 버전 시작 잔액을 동일 분모로 계획/실제 누적 원금 감소 비교. 홈 동심원은 최초 원금 대비 감소. 이번 달과 누적 도래회차 계획·실적 구분. track.status=ON_TRACK/BEHIND/AHEAD 정확한 금액 비교, 정기 무기록이면 UNRECORDED 별도; 실제 확인 미납·부분은 regular_due_status 별도. 확인 부족은 null/INSUFFICIENT; 도래 목표 0원은 비율 null. BULLET은 적립 목표 vs 적립 실적, 원금 진행 별도 표시. projected=최근 6개 완료 관측 월 실제 추가원금 평균(1~5개면 해당 평균, 0개면 계획 기준 FALLBACK_PLAN), 미기록 월 제외, 실제 0월 포함. BULLET은 실제 적립 평균 사용; 계약 만기에 자금 부족 시 null/부족 경고.
- 장기 변경은 다음 미도래 회차부터 새 plan_version, 과거 계획 보존. preview 저장 없음, 동일 입력 revision과 preview_version으로 저장, 최신 불일치 409 PLAN_PREVIEW_STALE/STRATEGY_STALE. 전략/전체 계획 원자적 반영; 직접 장기 수정은 다중 전략 MANUAL, 당월 배분은 변경하지 않음. 다중 PRO 전체 계획은 전략 최초 반영 이후만, 해지 시 개별 금액/기록 유지·전체/우선순위 숨김.
- 소유권·PRO 검증 및 공통 오류/금액/일자/동시성 규약 준수. 상태 변경 및 실제 기록 저장 시 공통 입력 revision 갱신, 관련 리포트 stale. GET/미리보기는 원본 변경 없음.
