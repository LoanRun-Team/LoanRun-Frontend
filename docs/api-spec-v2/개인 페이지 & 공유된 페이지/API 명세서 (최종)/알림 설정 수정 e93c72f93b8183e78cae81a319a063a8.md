# 알림 설정 수정

API Endpoint: /api/settings/notifications/
FE 연동: No
HTTP method: PATCH
Status: BE 구현전
Test: No
model: settings
메모: G1-d 앱 내 표시 토글 저장, 외부 발송 제외.
순서: 53

**기능:** 알림 설정 수정

**HTTP method:** `PATCH`

**API Endpoint:** `/api/settings/notifications/`

**인증:** 필수 (Authorization: Bearer {access_token})

## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| payment_due | boolean | 선택 | 납부 예정일 알림 |
| report_update | boolean | 선택 | 리포트 업데이트 알림 |
| `rate_reset` | boolean | 선택 | 금리 재설정일 알림 |
| `grace_end` | boolean | 선택 | 거치 종료일 알림 |

**요청 예시**

```jsx
PATCH /api/settings/notifications/
Authorization: Bearer <access_token>
Content-Type: application/json
```

```json
{
  "payment_due": true,
  "rate_reset": true,
  "grace_end": false,
  "report_update": true
}
```

## Response

### 성공 200

```json
{
  "success": true,
  "code": "NOTIFICATION_SETTINGS_UPDATE_SUCCESS",
  "message": "알림 설정을 저장했습니다.",
  "data": {
    "payment_due": true,
    "report_update": true,
    "rate_reset": true,
    "grace_end": false
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| `payment_due` | boolean | payment due 값(공통 규약) |
| `report_update` | boolean | 기준 날짜(YYYY-MM-DD) |
| `rate_reset` | boolean | 금리 재설정일 알림 |
| `grace_end` | boolean | 거치 종료일 알림 |

### 실패 응답

**실패 400 · VALIDATION_ERROR**

```json
{
  "success": false,
  "code": "VALIDATION_ERROR",
  "message": "입력값을 확인해 주세요.",
  "errors": {
    "rate_reset": [
      "boolean 값이어야 합니다."
    ]
  }
}
```

**실패 401 · AUTH_REQUIRED**

```json
{
  "success": false,
  "code": "AUTH_REQUIRED",
  "message": "로그인이 필요합니다.",
  "errors": {}
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 입력값을 확인해 주세요. |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- 전달된 4개 토글만 저장. 위험 분석 카드별 알림 없음, 외부 발송 및 예약 발송 제외.

**화면/기능 연결:** G1-d 앱 내 표시 토글 저장, 외부 발송 제외.
