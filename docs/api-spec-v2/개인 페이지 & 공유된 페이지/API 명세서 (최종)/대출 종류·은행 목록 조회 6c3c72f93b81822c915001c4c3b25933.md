## 처리 규칙 및 개발 참고

- 금융감독원 금융상품 한눈에 공시 카탈로그를 서버 DB 캐시로 조회. 주택담보·전세자금·개인신용대출의 지원 가능한 은행/유형만 제공하고, 공시 미지원 유형은 수동 입력 선택을 제공한다. 개인계좌 조회는 하지 않는다. 금감원 개인신용대출 상품의 유형 코드·명칭(실제 응답 확인 기준)으로 한도대출을 제외하고, 지원 상환방식만 반환한다. 명백한 한도대출은 캐시·seed·수기 등록에서도 제외한다. [query.loan](http://query.loan)_form은 생략 또는 GENERAL만 허용; 미지원 값은 400 VALIDATION_ERROR.
- API 키는 서버 환경변수에 저장. 매일 03:00 KST 갱신, 실패 시 최근 정상 캐시, 최초 실패 시 공식 출처 기반 seed 사용. 실제 키 발급·호출 검증 후 활성화.

**화면/기능 연결:** A S-01a~b. 금감원 공시 카탈로그 DB 캐시·seed fallback.
