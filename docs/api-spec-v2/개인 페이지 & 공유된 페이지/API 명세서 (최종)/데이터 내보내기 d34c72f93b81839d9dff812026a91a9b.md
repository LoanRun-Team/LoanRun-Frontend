**기능:** 데이터 내보내기

**HTTP method:** `GET`

**API Endpoint:** `/api/settings/export/`

**인증:** 필수 (Authorization: Bearer {access_token})

## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| `query.format` | string | 선택 | csv만 허용(기본 csv) |
| `query.start_month` | string(YYYY-MM) | 선택 | 내보낼 시작 월 |
| `query.end_month` | string(YYYY-MM) | 선택 | 내보낼 종료 월 |

**요청 예시**

```jsx
GET /api/settings/export/?format=csv
Authorization: Bearer <access_token>
```

Body 없음.

## Response

### 성공 200

파일 응답 (200 OK). JSON 성공 envelope 대신 아래 헤더와 CSV 본문을 반환합니다.

```jsx
Content-Type: text/csv; charset=utf-8
Content-Disposition: attachment; filename="ronrun-export.csv"
```

```jsx
record_type,loan_id,product_name,paid_at,amount,principal_amount,interest_amount,extra_amount,remaining_principal
loan,1,예시 신용대출,,,,,,6000000
```

```json
{
  "success": false,
  "code": "INVALID_EXPORT_FORMAT",
  "message": "지원하지 않는 파일 형식입니다.",
  "errors": {}
}
```

**실패 400 · INVALID_DATE_RANGE**

```json
{

  "code": "INVALID_DATE_RANGE",
```

```json
{
  "success": false,
  "code": "AUTH_REQUIRED",

  "errors": {}

```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `INVALID_EXPORT_FORMAT` | 지원하지 않는 파일 형식입니다. |
| 400 | `INVALID_DATE_RANGE` | 조회 기간을 확인해 주세요. |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- 성공 JSON envelope 예외: Content-Type text/csv; charset=utf-8, Content-Disposition: attachment; filename="ronrun-export.csv". 본인 대출·납부 기록만 CSV, 기간 필터는 납부에만 적용. Excel 전용 .xlsx/PDF 제외.
- 실패 공통 JSON envelope, 인증 필수. CSV 문자열은 수식 주입 방지.
- UTF-8 BOM 적용, 스키마: record_type,loan_id,product_name,paid_at,amount,principal_amount,interest_amount,extra_amount,remaining_principal. loan 행은 납부 필드 공란, payment 행 remaining_principal 공란.

**화면/기능 연결:** G1-e 내보내기. CSV(대출·납부) 확정, XLSX/PDF 제외.

- CSV 대출/납부 기준 유지. 실제 납부의 수수료·적립금 사용액을 별도 열로 제공하고, 삭제된 대출의 보존된 과거 거래 포함. 적립 거래는 대출 원금 감소로 집계하지 않음.
