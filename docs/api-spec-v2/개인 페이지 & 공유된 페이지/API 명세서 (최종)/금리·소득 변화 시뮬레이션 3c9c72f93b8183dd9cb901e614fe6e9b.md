순서: 44

**기능:** 금리·소득 변화 시뮬레이션

**HTTP method:** `POST`

**API Endpoint:** `/api/risks/simulate/`

**인증:** 필수 (Authorization: Bearer {access_token}) · PRO 권한 확인

## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| loan_ids | array<integer> | 선택 | 상세 대출 필터, 가계 계산은 전체 |
| scenario_type | string(enum) | 필수 | CURRENT / RATE_UP / INCOME_DOWN / EXPENSE_UP |

**요청 예시**

```jsx
POST /api/risks/simulate/
Authorization: Bearer <access_token>
Content-Type: application/json
```

```json
{
  "scenario_type": "RATE_UP"
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `SIMULATION_VALIDATION_ERROR` | 시뮬레이션 입력값을 확인해 주세요. |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |
| 403 | `PRO_REQUIRED` | PRO 이용자만 사용할 수 있습니다. |
| 404 | `LOAN_NOT_FOUND` | 대출을 찾을 수 없습니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- PRO; scenario_type 필수, 사용자 직접 변화량 입력 불가. loan_ids 선택은 상세 비교 필터, 가계 위험은 전체 기준. DB 변경 없음.
- 4개 지표: 여유자금 B/I×100(≥8 안정, ≥3<8 주의, <3 위험), 소득 대비 기본 정기 부담/I×100(<30 안정, 30~40 미만 주의, ≥40 위험), 선택 지출 실제/월 시작 한도×100(<90 안정, 90~100 주의, >100 위험; 둘 다 0 안정, 한도 0·사용 양수 위험, 비율 null), 변동금리 +1%p 시 기본+추가/적립 유지 가능 안정, 기본 가능·추가/적립 불가 주의, 기본 불가 위험; 변동 없음 안정. 자료 부족 null.
- 가중치 40/30/15/15 순서(안정=0, 주의=50, 위험=100). 점수 [0,25) STABLE, [25,60) CAUTION, ≥60 DANGER. 현재 기본 불가 위험 우선, 추가/적립 불가 또는 +1%p 기본 불가 최소 주의. 필수 데이터 부족 score/level null(확인된 기본 불가면 DANGER 우선). 규제 DSR/신용평가 아님.
- 시나리오 CURRENT, RATE_UP(+1%p, 변동만), INCOME_DOWN(−5%), EXPENSE_UP(당월 500000원 추가), 각각 독립 실행, 직접 슬라이더 값 제외. 3종 임계: 현재 목표 유지 불가 최초 변화량(B<추가 목표+필요 적립) / 기본 위험 최초 변화량(B<0); 이미 부족 0, 미도달/대상 없음 null. 금리 0~5%p 0.01 간격, 소득 0~100% 0.01 간격, 지출 원 단위(이월 전 B).
- 비상자금 대응 개월=emergency_fund/지속 월 부족액, 부족 없음 또는 정보 부족 null(사유 구분); 일회성 추가지출·만기 원금 부족은 별도 해당 월 부족액. 완납 가능성 HIGH 목표 유지, MEDIUM 기본 가능·목표 지연, LOW 기본 또는 만기 마련 불가, 자료 부족 null. 예측 확률 아님.
- 예정 이벤트 금리 재설정·거치 종료·만기일시 만기; 모든 미래 일정 표시, d_day 0~30 임박. 최근 6개 완료 관측 월 확정 데이터와 변경 이력만; 미입력 월 변화 생성 금지.
- 소유권·PRO 검증 및 공통 오류/금액/일자/동시성 규약 준수. 상태 변경 및 실제 기록 저장 시 공통 입력 revision 갱신, 관련 리포트 stale. GET/미리보기는 원본 변경 없음.

**화면/기능 연결:** E2 고정 시나리오·리포트 완납 가능성. PRO 금리·소득 시뮬레이션.
