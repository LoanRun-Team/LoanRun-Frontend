FE 연동: No

Status: BE 구현전

**기능:** 로그인

**HTTP method:** `POST`

**API Endpoint:** `/api/auth/login/`

**인증:** 불필요

## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| email | string(email) | 필수 | 가입 이메일 |
| password | string | 필수 | 비밀번호 |

**요청 예시**

```jsx
POST /api/auth/login/
Content-Type: application/json
```

```json
{
  "email": "demo@example.com",
  "password": "example-password"
}
```

## Response

### 성공 200

```json
{
  "success": true,
  "code": "LOGIN_SUCCESS",
  "message": "로그인했습니다.",
  "data": {
    "access_token": "sample.access.token",
    "refresh_token": "sample.refresh.token",
    "token_type": "Bearer",
    "user": {
      "user_id": 1,
      "email": "demo@example.com",
      "name": "민준",
      "occupation": "직장인",
      "income_type": "REGULAR",
      "onboarding_completed": false,
      "plan_type": "PRO"
    }
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| access_token | string | API 인증용 액세스 토큰 예시 |
| refresh_token | string | 갱신 토큰 예시 |
| token_type | string | Bearer |
| user | object | — |
| `user.user_id` | integer | 사용자 식별자 |
| `user.email` | string | — |
| `user.name` | string | — |
| `user.occupation` | string | — |
| `user.income_type` | string | — |
| `user.onboarding_completed` | boolean | — |
| `user.plan_type` | string | FREE 또는 PRO |

### 실패 응답

**실패 400 · VALIDATION_ERROR**

```json
{
  "success": false,
  "code": "VALIDATION_ERROR",
  "message": "입력값을 확인해 주세요.",
  "errors": {
    "email": [
      "필수 항목입니다."
    ]
  }
}
```

**실패 401 · INVALID_CREDENTIALS**

```json
{
  "success": false,
  "code": "INVALID_CREDENTIALS",
  "message": "이메일 또는 비밀번호가 올바르지 않습니다.",
  "errors": {}
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 입력값을 확인해 주세요. |
| 401 | `INVALID_CREDENTIALS` | 이메일 또는 비밀번호가 올바르지 않습니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- 이메일/비밀번호 + JWT Bearer 인증 확정. 액세스 15분, 갱신 7일. 실패 메시지로 계정 존재 여부를 구분하지 않는다.

**화면/기능 연결:** 이메일/비밀번호 + JWT 인증 확정.
