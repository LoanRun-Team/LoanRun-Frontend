## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| `query.loan_type` | string | 선택 | CREDIT 등 대출 유형 |

**요청 예시**

```jsx

```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 입력값을 확인해 주세요. |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |
| 404 | `INSTITUTION_NOT_FOUND` | 금융기관을 찾을 수 없습니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- 내부 캐시를 은행/유형 기준으로 조회. 결과 없음은 products:[]; 외부 API 오류에도 마지막 정상 캐시 또는 seed 사용. 금감원 개인신용대출 상품의 유형 코드·명칭(실제 응답 확인 기준)으로 한도대출을 제외하고, 지원 상환방식만 반환한다. 명백한 한도대출은 캐시·seed·수기 등록에서도 제외한다. [query.loan](http://query.loan)_form은 생략 또는 GENERAL만 허용; 미지원 값은 400 VALIDATION_ERROR.
- 상품명과 공시 참고 정보만 제공. 공시값은 개인 약정 금리·원금·잔액·만기·상환조건이 아니므로 개인 계약값은 수기 입력. 미등록 상품 직접 입력 허용. 금리·상환방식이 공시되지 않으면 추정하지 않는다.
