# 회원가입

API Endpoint: /api/auth/signup/
FE 연동: No
HTTP method: POST
Status: BE 구현전
Test: No
model: users
메모: 이메일/비밀번호 + JWT 인증 확정. 가입 FREE.

**기능:** 회원가입

**HTTP method:** `POST`

**API Endpoint:** `/api/auth/signup/`

**인증:** 불필요

## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| email | string(email) | 필수 | 로그인 이메일, 중복 불가 |
| password | string | 필수 | 8자 이상, UTF-8 72바이트 이하 |
| name | string | 필수 | 1~50자 |

**요청 예시**

```jsx
POST /api/auth/signup/
Content-Type: application/json
```

```json
{
  "email": "demo@example.com",
  "password": "example-password",
  "name": "민준"
}
```

## Response

### 성공 201

```json
{
  "success": true,
  "code": "SIGNUP_SUCCESS",
  "message": "회원가입을 완료했습니다.",
  "data": {
    "user_id": 1,
    "email": "demo@example.com",
    "name": "민준"
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| user_id | integer | 사용자 식별자 |
| email | string | — |
| name | string | — |

### 실패 응답

**실패 400 · VALIDATION_ERROR**

```json
{
  "success": false,
  "code": "VALIDATION_ERROR",
  "message": "입력값을 확인해 주세요.",
  "errors": {
    "password": [
      "8자 이상 입력해 주세요."
    ]
  }
}
```

**실패 409 · EMAIL_ALREADY_EXISTS**

```json
{
  "success": false,
  "code": "EMAIL_ALREADY_EXISTS",
  "message": "이미 등록된 이메일입니다.",
  "errors": {}
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 입력값을 확인해 주세요. |
| 409 | `EMAIL_ALREADY_EXISTS` | 이미 등록된 이메일입니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- 이메일/비밀번호 + JWT 인증 확정. 비밀번호 8자 이상, UTF-8 72바이트 이하, BCrypt 해시 저장. 원문 응답/로그 금지. 가입 직후 FREE 및 onboarding_completed=false.

**화면/기능 연결:** 이메일/비밀번호 + JWT 인증 확정. 가입 FREE.
