# 로그인 토큰 갱신

API Endpoint: /api/auth/refresh/
FE 연동: No
HTTP method: POST
Status: BE 구현전
Test: No
model: users
메모: JWT 토큰 갱신 필수; 액세스 15분·갱신 7일.
순서: 3

**기능:** 로그인 토큰 갱신

**HTTP method:** `POST`

**API Endpoint:** `/api/auth/refresh/`

**인증:** 불필요

## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| refresh_token | string | 필수 | 발급받은 갱신 토큰 |

**요청 예시**

```jsx
POST /api/auth/refresh/
Content-Type: application/json
```

```json
{
  "refresh_token": "sample.refresh.token"
}
```

## Response

### 성공 200

```json
{
  "success": true,
  "code": "TOKEN_REFRESH_SUCCESS",
  "message": "로그인 토큰을 갱신했습니다.",
  "data": {
    "access_token": "sample.new.access.token",
    "token_type": "Bearer"
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| access_token | string | API 인증용 액세스 토큰 예시 |
| token_type | string | Bearer |

### 실패 응답

**실패 400 · VALIDATION_ERROR**

```json
{
  "success": false,
  "code": "VALIDATION_ERROR",
  "message": "입력값을 확인해 주세요.",
  "errors": {
    "refresh_token": [
      "입력값이 올바르지 않습니다."
    ]
  }
}
```

**실패 401 · INVALID_REFRESH_TOKEN**

```json
{
  "success": false,
  "code": "INVALID_REFRESH_TOKEN",
  "message": "갱신 토큰이 유효하지 않거나 만료되었습니다.",
  "errors": {}
}
```

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 입력값을 확인해 주세요. |
| 401 | `INVALID_REFRESH_TOKEN` | 갱신 토큰이 유효하지 않거나 만료되었습니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- JWT 액세스 토큰 15분, 갱신 토큰 7일. 갱신 시 기존 응답 구조대로 액세스 토큰만 신규 발급, 갱신 토큰 회전 없음. 만료 및 탈퇴/로그아웃으로 무효화된 토큰은 거부.

**화면/기능 연결:** JWT 토큰 갱신 필수; 액세스 15분·갱신 7일.
