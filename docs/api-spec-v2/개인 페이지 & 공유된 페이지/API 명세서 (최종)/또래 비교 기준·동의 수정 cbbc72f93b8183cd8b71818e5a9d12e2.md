Status: BE 구현전

model: reports
메모: F4-c 동의/비교 없이 보기, F4-d 기준 변경.

**기능:** 또래 비교 기준·동의 수정

**HTTP method:** `PATCH`

**API Endpoint:** `/api/reports/comparison-settings/`

**인증:** 필수 (Authorization: Bearer {access_token}) · PRO 권한 확인

## Request

| 필드 | Type | 필수 | 설명 |
| --- | --- | --- | --- |
| consented | boolean | 선택 | 비교 동의/철회 |
| age_group | string 또는 null | 조건부 | AGE_20S, AGE_30S, AGE_40S, AGE_50_PLUS |
| `income_decile` | integer 또는 null | 조건부 | 동의 시 1~5 직접 선택 |

**요청 예시**

```jsx
PATCH /api/reports/comparison-settings/
Authorization: Bearer <access_token>
Content-Type: application/json
```

```json
{
  "consented": true,
  "age_group": "AGE_20S",
  "income_decile": 3
}
```

## Response

### 성공 200

```json
{
  "success": true,
  "code": "REPORT_COMPARISON_SETTINGS_UPDATE_SUCCESS",
  "message": "비교 기준 및 동의를 저장했습니다.",
  "data": {
    "consented": true,
    "age_group": "AGE_20S",
    "source_type": "DEMO",
    "regeneration_required": true,
    "income_decile": 3
  }
}
```

**data 필드** (중첩 객체는 JSON 예시와 공통 스키마 기준)

| 필드 | Type | 정의 |
| --- | --- | --- |
| `consented` | boolean | 또래 비교 동의 여부 |
| `age_group` | string 또는 null | 사용자 선택 연령대 |
| `source_type` | string | 데이터 출처 |
| `regeneration_required` | boolean | regeneration required 값(공통 규약) |
| `income_decile` | integer 또는 null | 사용자가 직접 선택한 소득 그룹 1~5; 실제 통계 아님 |

## `GlobalExceptionHandler.java` 처리 기준

| HTTP status | code | message |
| --- | --- | --- |
| 400 | `COMPARISON_SETTINGS_INVALID` | 또래 비교 기준을 확인해 주세요. |
| 401 | `AUTH_REQUIRED` | 로그인이 필요합니다. |
| 403 | `PRO_REQUIRED` | PRO 이용자만 사용할 수 있습니다. |

공통 예외 응답은 프로젝트 공통 규약을 따릅니다. 동일 HTTP status여도 발생 원인에 따라 code를 구분합니다.

## 처리 규칙 및 개발 참고

- PRO; consented=true이면 age_group AGE_20S/AGE_30S/AGE_40S/AGE_50_PLUS 및 income_decile 1~5 필수. false면 비교에 사용하지 않음. 변경 시 stale, 별도 즉시 배치 없음.
- 최근 6개 완료 관측 월, 1~5개월이면 확인 가능한 기간; 미관측을 0으로 채우지 않음. 월 원금 상환률 = (정기+추가 실제 원금)/월초 잔액×100, 월중 등록은 등록 잔액 추가; 평균은 관측 월들의 산술평균. 6개월 원금 감소율=실제 원금 합계/(시작 잔액+등록 잔액)×100, 삭제·완납된 대출의 실제 과거 기록 보존, 삭제·잔액 보정은 원금납부로 집계하지 않음. 소득 대비 실제 월 원금·이자/실제 소득 비율의 관측월 평균, 추가원금 포함 납부 건당 1회. 적립 실적 별도. 자료 부족 null.
- 또래 비교 PRO 동의 사용자만: 20대/30대/40대/50대 이상, 사용자 선택 소득 1~5 그룹(호환 income_decile 키), 고정 가상 평균 DEMO, 실제 통계·순위·백분위·표본수 금지. 동의 없어도 개인 리포트/전략 제공. 미관측 본인 수치를 가상값으로 대체 금지.
- 리포트는 첫 진입 또는 관련 데이터 revision/완료월/동의 변경(stale) 시 POST 요청, GET 조회 전용. 변경 없으면 기존 완료 결과 반환, 생성 중이면 동일 job/report_id 반환, FAILED 재시도 60초 제한, 일괄 자동 배치 없음. 생성 중 입력 바뀌면 result stale, 최신 표시 금지. 홈 is_new는 최신 완료 생성 24시간 이내+stale=false; FREE는 잠금 및 날짜/N 숨김. AI는 서버 확정 수치·전략 코드 해석/문구만, 실패 시 기본 문구로 대체.
- 소유권·PRO 검증 및 공통 오류/금액/일자/동시성 규약 준수. 상태 변경 및 실제 기록 저장 시 공통 입력 revision 갱신, 관련 리포트 stale. GET/미리보기는 원본 변경 없음.

**화면/기능 연결:** F4-c 동의/비교 없이 보기, F4-d 기준 변경.
